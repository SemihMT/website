PPMEdit

2024 · Solo project
GitHub ↗
Python TKinter

Overview

PPMEdit is a small level editing tool I built in Python using the Tkinter GUI library. I created it to speed up level creation for the P4Engine Bubble Bobble project, where levels are represented as 32×26 pixel PPM images.

Each pixel in the image corresponds directly to a tile in the game world. Besides editing pixel colors, the tool allows metadata to be attached to individual pixels. This makes it possible to store both the visual layout and the gameplay information for a level in a single file.

Key Features

Canvas and Pixel Editing

  • 32×26 pixel canvas: Mirrors the exact level layout used by the game engine, where each pixel represents a tile.
  • Palette-based painting: Users can select colors from a palette and paint directly onto the grid.
  • Painting and erasing: Tiles can easily be placed, modified, or cleared during level design.

Metadata System

  • Per-pixel metadata: Additional information such as tile type or special properties can be assigned to any pixel.
  • Tooltip inspection: Hovering over a pixel reveals its metadata, making it easy to inspect level logic while editing.
  • Integrated storage: Metadata is saved alongside the pixel data so the full level definition is preserved in a single file.

File Management

  • Save PPM files: Export levels in a format directly compatible with the engine.
  • Load existing levels: Open and continue editing previously created maps.

def open_ppm(self):
    file_path = filedialog.askopenfilename(filetypes=[("PPM files", "*.ppm")])
    if not file_path:
        return

    with open(file_path, 'rb') as f:
        ppm_type = f.readline().strip()
        if ppm_type not in [b"P3", b"P6"]:
            messagebox.showerror("Error", "Invalid PPM file.")
            return

        metadata = {}
        dimensions = f.readline().strip()
        while dimensions.startswith(b"#"):
            if dimensions.startswith(b"# Metadata:"):
                parts = dimensions.split(b":", 1)[1].strip().split(b" ", 2)
                if len(parts) == 3:
                    x_str = parts[0].split(b",")[0].lstrip(b"(")
                    y_str = parts[1].rstrip(b")")
                    try:
                        x, y = int(x_str), int(y_str)
                        comment = parts[2].decode('utf-8')
                        metadata[(x, y)] = comment
                    except ValueError:
                        pass
            dimensions = f.readline().strip()

        width, height = map(int, dimensions.split())
        max_color = int(f.readline().strip())

        if self.width != width or self.height != height:
            messagebox.showerror("Error", "Dimensions do not match the current canvas size.")
            return

        if ppm_type == b"P3":
            pixel_data = f.read().decode('utf-8').split()
            index = 0
            for y in range(self.height):
                for x in range(self.width):
                    r, g, b = map(int, pixel_data[index:index+3])
                    index += 3
                    color = f"#{r:02x}{g:02x}{b:02x}"
                    self.canvas.itemconfig(self.grid[y][x], fill=color)
        else:  # P6
            pixels = f.read(self.width * self.height * 3)
            index = 0
            for y in range(self.height):
                for x in range(self.width):
                    r, g, b = pixels[index:index+3]
                    index += 3
                    color = f"#{r:02x}{g:02x}{b:02x}"
                    self.canvas.itemconfig(self.grid[y][x], fill=color)

        self.metadata = metadata

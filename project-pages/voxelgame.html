Solo Project

Voxel Editor

2024 · Solo project · Vulkan / C++
GitHub ↗
C++ Vulkan CMake School

Overview

A first-person voxel world editor written from scratch in C++ using the Vulkan API. The project was created as a deep dive into low-level graphics programming and is inspired by games such as Minecraft. The world is procedurally generated using simplex noise and divided into 16×16×16 block chunks that load and unload dynamically as the player moves through the world.

Technical Highlights

  • Custom Vulkan renderer: Implemented the full rendering pipeline directly on top of Vulkan, including swap chains, render passes, descriptor sets, and vertex and index buffers. No abstraction layer or rendering framework is used.
  • Texture atlas mapping via enum: Block types are defined in a VoxelType enum where the underlying value represents the texture atlas index. A constexpr helper computes this mapping at compile time so a single value encodes both the block type and its texture without any runtime cost.
  • Dynamic chunk system: The world is divided into 16³ chunks. As the player moves, chunks outside a configurable view distance are unloaded while new chunks are generated on demand. This keeps memory usage bounded while allowing the world to extend indefinitely.
  • Procedural terrain generation: Terrain height and biome variation are generated using layered simplex noise. This produces natural looking landscapes without any authored terrain data.
  • Chunk mesh generation: Faces between solid neighboring voxels are culled during mesh generation, significantly reducing the number of vertices sent to the GPU.

Block Type as Texture Index

+

A constexpr function converts a texture atlas row/column pair into a flat index at compile time. The VoxelType enum uses this as its underlying value, so the block's type and its texture coordinate are the same integer — no lookup table needed. 

namespace vxl
{
    constexpr uint32_t RowColToIdx(const glm::vec<2, uint32_t>& rowCol, int gridsize = 32)
    {
        return rowCol.x * gridsize + rowCol.y;
    }

    class vxlBlock
    {
    public:
        enum class VoxelType : uint32_t
        {
            Air         = 0,
            Stone       = RowColToIdx({26, 6}),
            Dirt        = RowColToIdx({13, 21}),
            GrassSide   = RowColToIdx({ 8, 25}),
            GrassTop    = RowColToIdx({10, 26}),
            Sand        = RowColToIdx({23, 16}),
            OakPlanks   = RowColToIdx({18,  7}),
            OakLog      = RowColToIdx({18,  5}),
            OakLeaves   = RowColToIdx({18,  4}),
            CobbleStone = RowColToIdx({14, 13}),
            Bricks      = RowColToIdx({ 9,  9}),
            Glass       = RowColToIdx({15, 24}),
        };

        vxlBlock(const glm::vec3& worldPosition, VoxelType type);

        void      SetType(VoxelType type)       { m_type     = type; }
        void      SetPosition(const glm::vec3& pos) { m_position = pos;  }
        VoxelType GetType()     const           { return m_type;     }
        glm::vec3 GetPosition() const           { return m_position; }

    private:
        glm::vec3 m_position;
        VoxelType m_type;
    };
}

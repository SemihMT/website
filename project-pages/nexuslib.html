Graduation Project

Nexus Networking Library

2024–2025 · Solo project · C++ / ASIO / CMake
GitHub ↗
C++ CMake CI/CD School

Overview

Nexus is a high-level C++ networking library built on top of ASIO, designed as my graduation project at DAE. The central question was whether low-level networking complexity could be abstracted into a developer-friendly API without sacrificing the performance that online multiplayer games demand.

The library was benchmarked against ENet and raw ASIO across three common multiplayer patterns (connect/disconnect, ping-pong, inter-client messaging) and two performance dimensions (latency and throughput). The results showed that Nexus reduces lines of code by up to 64.5% and cyclomatic complexity by up to 71.9% compared to ENet, while maintaining competitive latency, though with a throughput trade-off introduced by the message abstraction layer.

Design Goals

  • No non-game boilerplate: Users should be able to get straight to writing game networking code. Some setup is required, but it should be entirely game-specific. No scaffolding just to satisfy the library.
  • Usable with minimal networking knowledge: Nexus shouldn't require understanding the OSI model to get started, while still being configurable enough for experienced developers to tune it to their needs.
  • Expressive API: The goal was an API so readable that even a non-programmer could look at a Nexus client setup and understand it. Influenced by the Fluent Interface pattern and the Named Parameter Idiom. Method chaining replaces constructor argument ordering and reduces cognitive load.

Technical Highlights

  • High-level API over ASIO: Encapsulated ASIO's async I/O into nxs::Server, nxs::Client, and nxs::Connection classes with event handler callbacks. This lets users implement a server in a handful of lines rather than managing io_context, acceptors, and async chains directly.
  • Typed message system: Messages are templated on a user-defined enum, so the compiler enforces message type safety. A Message<T> carries a typed header and a variable-size byte payload, serialised into a contiguous buffer before sending. Custom handling for std::string is built in.
  • Worker thread isolation: All ASIO async I/O runs on a dedicated worker thread created at nxs::Nexus::Init(). This means the user's game loop is never blocked by networking, and adding Nexus to an existing game is as simple as initialising it alongside the game loop.
  • Cross-platform CI pipeline: CMake + GitHub Actions builds and tests Debug and Release configurations on windows-latest, ubuntu-latest, and macos-latest on every push. Release binaries are uploaded as artifacts automatically. Cross-platform compatibility was validated in practice by running the demo server on a Steam Deck (Linux) with Windows PCs as clients.
  • Measured trade-offs: Latency was competitive with raw ASIO (293µs vs. 255µs average round-trip). Throughput was lower (~3 MB/s vs. ~5.1 MB/s for ASIO), traced to overhead in the Message abstraction layer, a conscious trade-off documented in the research paper.
This project is also the subject of a formal research paper: Cross-Platform Multiplayer Made Simple: The Nexus Networking Library, available on request.

Connect / Disconnect: full working example

+

A server that accepts a client and immediately disconnects it, implemented in a single file, ~30 lines. The equivalent ENet implementation required ~65 lines and higher cyclomatic complexity.

#include <nexus/nexus.h>
#include <nexus/server.h>
#include <nexus/client.h>
#include <iostream>

enum class MyMessageType : uint32_t
{
    Connect,
    Disconnect,
};

int main(int argc, char* argv[])
{
    nxs::Nexus::Init();

    if (std::string(argv[1]) == "--server")
    {
        nxs::Server<MyMessageType> server{};

        server.AddEventHandler(nxs::Server<MyMessageType>::ServerEvent::OnConnect,
            [&](std::shared_ptr<nxs::Connection<MyMessageType>> connection)
            {
                std::cout << "[SERVER] Client [" << connection->GetID() << "] connected!\n";
                connection->Disconnect();
            });

        server.Run(true);
    }
    else if (std::string(argv[1]) == "--client")
    {
        nxs::Client<MyMessageType> client;
        client.Connect("localhost", 60000);

        client.AddEventHandler(nxs::Client<MyMessageType>::ClientEvent::OnConnect,
            [&]() { std::cout << "[" << client.GetID() << "] Connected\n"; });

        client.AddEventHandler(nxs::Client<MyMessageType>::ClientEvent::OnDisconnect,
            [&]() { std::cout << "[" << client.GetID() << "] Disconnected\n"; });

        while (true) {}
    }

    nxs::Nexus::Shutdown();
    return 0;
}
